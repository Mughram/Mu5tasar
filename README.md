# Mu5tasar

Mu5tasar is a simple PHP quiz platform for creating and taking quizzes with **five questions** each.

We built it as a group mini-project for our **Web Programming course at Jazan University**, applying what we learned about PHP, databases, and web vulnerabilities such as SQL injection, XSS, and CSRF.

Built with PHP, PostgreSQL (Supabase), HTML, CSS, and Bootstrap.
